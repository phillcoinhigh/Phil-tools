Token utilities, written in Phil

The tools token projects reach for every day: a locker, transfer hooks, vesting, a treasury, an auction, a launch curve. Each is a complete Phil program you can run here and fork. Coins are linear values and every rule about money is a written promise, so the mistakes that drain contracts are the ones Phil refuses.

They run as simulations today. When Phil can deploy to a chain, these are the starting point: each one lists what an on-chain version still needs.
