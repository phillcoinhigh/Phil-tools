What changed in Phil

Phil moves fast and most of it happens in commit messages. This page reads the repository's history once a day and counts what landed: new test programs, design notes, proofs, compiler modules, and whether the grammar moved.

How our tools kept up

Each row is a Phil commit our daily job ran against. If a number drops, Phil changed and we have catching up to do.

How this is produced

Everything above is counted from abiggerhammer/phil's git history by changelog/run.ts. Nothing is summarised by hand or by a model. The lines under “in the repository's own words” are commit subjects, linked to the commits. Dates are commit dates.
